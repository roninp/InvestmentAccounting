# Локальный запуск сервиса «Ребалансировка портфеля»

## Что это

Сервис — это **единый Node.js-процесс** (`server/index.js`), который одновременно:
- раздаёт страницу (`GET /` → `index.html`),
- отдаёт API цен (`GET /api/prices`),
- отвечает на проверку (`GET /health`).

Фронтенд и API находятся в одном origin. Поэтому приложение открывается
**только через адрес сервера** (`http://localhost:8787/`), а не двойным кликом
по `index.html`.

## Требования

- **Node.js** (>= 18). Проверка: `node --version`.
- (опционально) `git` для клонирования.

## Быстрый запуск (рекомендуемый способ)
Запустите **`start-server.bat`** (лежит в корне проекта). Скрипт сам:
1. проверяет, что Node.js установлен;
2. создаёт `server/.env` из `server/.env.example`, если его нет;
3. при необходимости выполняет `npm install`;
4. запускает сервер **в фоне** и автоматически открывает браузер на `http://localhost:8787/`.
Окно bat закрывается сразу, сервер продолжает работать.

Для остановки сервера запустите **`stop-server.bat`**.

## Запуск вручную

```bash
cd d:\ClaudeProjects\InvestmentAccounting\server

# 1) Первый раз: поставить зависимости (если папки node_modules нет)
npm install

# 2) Создать конфиг из шаблона (если server/.env ещё нет)
copy .env.example .env   # (Linux/macOS: cp .env.example .env)

# 3) Заполнить в server/.env секрет Finam Trade API (для тарифа «Про»):
#    FINAM_API_SECRET="tapi_sk_..."
#    PORT=8787
#    FINAM_TLS_INSECURE=1   # ТОЛЬКО локально, для корпоративного SSL

# 4) Запустить сервер
npm start                  # (= node index.js)
```

## Открытие приложения

Перейдите в браузере на:

```
http://localhost:8787/
```

Проверка работы:

| Адрес | Ожидаемый результат |
|-------|----------------------|
| `http://localhost:8787/` | Страница приложения (HTML) |
| `http://localhost:8787/health` | `{"ok":true,"finamConfigured":true}` |
| `http://localhost:8787/api/prices?tickers=SBER` | `{"prices":[276.15],...}` (если Finam настроен) |

## Важно

- Открывать именно `http://localhost:8787/`. Если открыть `index.html` как файл
  (`file://`) или через сторонний live-server, запросы `/api/prices` не попадут
  на сервер, и «Обновить цены» на тарифе «Про» не будет работать.
- Порядок: сначала сервер (start-server.bat или npm start), потом страница.
- `.env` содержит секрет — файл в `.gitignore`, не коммитить.
