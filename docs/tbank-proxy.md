# Backend-прокси T-Invest API (тариф «Про»)

## Общее описание

Модуль для мгновенного обновления цен **без задержки** на тарифе **Про** через
[API Т-Банка (T-Invest)](https://developer.tbank.ru/invest/intro/intro).

T-Invest API работает по протоколу **gRPC (protobuf)** и требует **секретный токен**,
поэтому браузерное приложение (`index.html`) не может обращаться к нему напрямую
(нет CORS и безопасного способа хранить токен на клиенте). Это решается
backend-прокси:

```
index.html (браузер)  --HTTP/JSON-->  server/index.js (Node)  --gRPC-->  T-Invest API
                                    (хранит токен в server/.env)
```

| Тариф        | Источник цен                     | Cooldown кнопки «Обновить цены» |
|--------------|----------------------------------|---------------------------------|
| Бесплатный   | ISS-API Мосбиржи (`MoexPriceService`) | нет (без ограничений) |
| Базовый      | ISS-API Мосбиржи (`MoexPriceService`) | нет (без ограничений) |
| Про          | T-Invest API через прокси (`TBankProxyPriceService`) | 60 секунд (с посекундным счётчиком) |

Cooldown 60 секунд применяется **только на тарифе «Про»**.
Разница тарифов — также в источнике и задержке котировок:
- **Про** — T-Invest API: котировки без задержки (режим реального времени), но кнопка доступна раз в 60 секунд.
- **Бесплатный / Базовый** — ISS-API Мосбиржи: данные с задержкой ~15 минут, кнопку можно нажимать в любой момент.

## Ключевые зависимости

- **Node.js** >= 16
- `@tinkoff/invest-js` — официальный JS SDK T-Invest API (gRPC)
- `express` — HTTP-сервер
- `dotenv` — чтение `server/.env`

Файлы модуля:
- `server/index.js` — сервер-прокси
- `server/package.json` — зависимости и скрипт запуска
- `server/.env.example` — шаблон конфигурации (коммитится)
- `server/.env` — реальная конфигурация с токеном (**в .gitignore, не коммитить**)

## Переменные окружения (server/.env)

| Переменная     | Обязательная | Описание                                                                 |
|----------------|--------------|--------------------------------------------------------------------------|
| `TINVEST_TOKEN`| да           | Персональный токен T-Invest API (получается в приложении Т-Инвестиций)   |
| `PORT`         | нет (8787)   | Порт, на котором слушает прокси (должен совпадать с `TBANK_PROXY_URL`)   |

## Экспортируемый API (эндпоинты)

### `GET /health`
Проверка работоспособности.
Ответ: `{ "ok": true, "tbankConfigured": boolean }`.

### `GET /api/prices?tickers=SBER,GAZP`
Получение цен и размеров лотов по списку тикеров (через запятую).
Ответ (тот же формат, что у `MoexPriceService.fetchPrices`):
```json
{
  "prices":  [246.1, 146.4],
  "lotSizes":[10, 10],
  "errors":  []
}
```
- `prices[i]` — цена последней сделки (`units + nano/1e9`) либо `null`
- `lotSizes[i]` — размер лота из справочника инструмента либо `null`
- `errors` — сообщения об ошибках по отдельным тикерам (частичный сбой одного тикера не ломает остальные)

Тикеры обрабатываются последовательно, чтобы не превышать лимиты API.

## Установка и запуск

```bash
cd server
npm install

# Скопировать шаблон в .env и вписать реальный токен
copy .env.example .env   # (Linux/macOS: cp)

npm start                # прокси на http://localhost:8787
```

## Интеграция с frontend (index.html)

- Константа `TBANK_PROXY_URL` (по умолчанию `http://localhost:8787`) задаёт адрес прокси.
- Класс `TBankProxyPriceService.fetchPrices(tickers)` вызывается из `handleRefreshPrices`
  только когда `tier === 'pro'`; на остальных тарифах по-прежнему используется
  `MoexPriceService` (ISS-API Мосбиржи).
- Открывать приложение стоит после запуска прокси, чтобы тариф «Про» мог
  получать цены.

## Важное примечание по безопасности

Секретный токен хранится **только** в `server/.env`. Этот файл добавлен в
`.gitignore` и не должен коммититься. Никогда не выносите токен в клиентский код.
