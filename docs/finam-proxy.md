# Backend-прокси Finam Trade API (тариф «Про»)

## Общее описание

Модуль для мгновенного обновления цен **без задержки** на тарифе **Про** через
[Finam Trade API](https://api.finam.ru/getting-started/) (REST-протокол).

Finam Trade API выдаёт короткоживущий **JWT-токен** (15 минут) на основе секретного
ключа (`FINAM_API_SECRET`) и требует наличие счёта в Финаме. Браузерное приложение
(`index.html`) не может обращаться к API напрямую: секрет нельзя хранить на клиенте,
а JWT нужно регулярно перевыпускать. Это решается backend-прокси:

```
index.html (браузер)  --HTTP/JSON-->  server/index.js (Node)  --HTTP (JWT)-->  api.finam.ru
                                    (хранит секрет в server/.env)
```

| Тариф        | Источник цен                                   | Cooldown кнопки «Обновить цены» |
|--------------|------------------------------------------------|---------------------------------|
| Бесплатный   | ISS-API Мосбиржи (`MoexPriceService`)         | нет (без ограничений)           |
| Базовый      | ISS-API Мосбиржи (`MoexPriceService`)         | нет (без ограничений)           |
| Про          | Finam Trade API через прокси (`TBankProxyPriceService`) | 60 секунд (с посекундным счётчиком) |

Cooldown 60 секунд применяется **только на тарифе «Про»**.
Разница тарифов — также в источнике и задержке котировок:
- **Про** — Finam Trade API: котировки без задержки (режим реального времени), но кнопка доступна раз в 60 секунд.
- **Бесплатный / Базовый** — ISS-API Мосбиржи: данные с задержкой ~15 минут, кнопку можно нажимать в любой момент.
- Если Finam-прокси недоступен или цены получить не удалось — frontend автоматически
  делает фолбэк на ISS-API Мосбиржи и показывает плашку о задержке данных.

## Поддерживаемые инструменты

Тариф «Про» через Finam поддерживает **только российские бумаги Мосбиржи**
(площадка **MISX**):
- обычный тикер (например `SBER`) резолвится напрямую в символ `SBER@MISX`;
- **ISIN** (например `RU0009029540`) резолвится через каталог инструментов Finam
  (`GET /v1/assets/all`, жёсткая фильтрация по `mic = MISX`, кэш 1 час);
- иностранные/прочие инструменты через Finam не ищутся — на них сработает фолбэк
  на ISS-API Мосбиржи.

## Ключевые зависимости

- **Node.js** >= 18 (используется встроенный `fetch`)
- `express` — HTTP-сервер
- `dotenv` — чтение `server/.env`

Файлы модуля:
- `server/index.js` — сервер-прокси
- `server/package.json` — зависимости и скрипт запуска
- `server/.env.example` — шаблон конфигурации (коммитится)
- `server/.env` — реальная конфигурация с секретом (**в .gitignore, не коммитить**)

## Переменные окружения (server/.env)

| Переменная          | Обязательная | Описание                                                                 |
|---------------------|--------------|--------------------------------------------------------------------------|
| `FINAM_API_SECRET`  | да           | Секретный токен Finam Trade API (портал https://api.finam.ru/tokens/)     |
| `PORT`              | нет (8787)   | Порт, на котором слушает прокси (должен совпадать с `TBANK_PROXY_URL`)    |
| `FINAM_TLS_INSECURE`| нет          | `"1"` отключает проверку TLS-сертификата (только для локальной разработки при корпоративном SSL-перехвате) |

## Как работает JWT

1. Прокси получает JWT из секрета: `POST /v1/sessions` c телом `{"secret": "..."}`.
2. Кэширует JWT и перевыпускает его за 1 минуту до истечения (JWT живёт 15 минут).
3. При ответе `401` (протух между проверками) автоматически получает новый JWT и
   повторяет запрос один раз.

## Экспортируемый API (эндпоинты)

### `GET /health`
Проверка работоспособности.
Ответ: `{ "ok": true, "finamConfigured": boolean }`.

### `GET /api/prices?tickers=SBER,GAZP`
Получение цен и размеров лотов по списку тикеров (через запятую).
Ответ (тот же формат, что у `MoexPriceService.fetchPrices`):
```json
{
  "prices":   [246.1, 146.4],
  "lotSizes": [10, 10],
  "errors":   []
}
```
- `prices[i]` — цена последней сделки из ответа LastQuote
  (`GET /v1/instruments/{symbol}/quotes/latest`, поле `quote.last.value`;
  фолбэк на `quote.close.value`) либо `null`
- `lotSizes[i]` — размер лота из справочника инструмента
  (`GET /v1/assets/{symbol}`, поле `lot_size.value`) либо `null`
- `errors` — сообщения об ошибках по отдельным тикерам (частичный сбой одного
  тикера не ломает остальные)

Тикеры обрабатываются последовательно, чтобы не превышать лимиты API (200 запросов в минуту на метод).

Прокси использует два источника данных: основной — эндпоинт Финам /v1/assets/{symbol}/params, и резервный (fallback) — MOEX ISS.Поле trade_lot_size на выходе из прокси возвращается в виде строки (string).

## Установка и запуск

```bash
cd server
npm install

# Скопировать шаблон в .env и вписать реальный секрет
copy .env.example .env   # (Linux/macOS: cp)

npm start                # прокси на http://localhost:8787
```

## Интеграция с frontend (index.html)

- Константа `TBANK_PROXY_URL` (по умолчанию `http://localhost:8787`) задаёт адрес прокси.
- Класс `TBankProxyPriceService.fetchPrices(tickers)` вызывается из `handleRefreshPrices`
  только когда `tier === 'pro'`; на остальных тарифах по-прежнему используется
  `MoexPriceService` (ISS-API Мосбиржи).
- Логика приёма цен и контракты ответов на frontend **не менялись** — прокси отдаёт
  JSON в совместимом формате.
- Открывать приложение стоит после запуска прокси, чтобы тариф «Про» мог получать цены.

## Важное примечание по безопасности

Секретный токен хранится **только** в `server/.env`. Этот файл добавлен в
`.gitignore` и не должен коммититься. Никогда не выносите секрет в клиентский код.

## Примечания по Finam API

- **HTTP-версия:** Finam рекомендует протокол HTTP/2, однако параметры REST-методов
  корректно работают и по HTTP/1.1 (проверено вручную на методах Auth и последних котировок).
  При необходимости прокси можно перевести на HTTP/2.
- **Лимиты:** не более 200 запросов в минуту на один метод. Каталог и размер лотов
  кэшируются, чтобы не упираться в лимиты при регулярном обновлении цен.
- **JWT:** короткоживущий (15 минут), генерируется метод `Auth` (`POST /v1/sessions`).
- **Обслуживание:** ежедневно с 05:00 до 06:15 по Москве сервис может быть недоступен.
